# Calendario de eventos espaciales

Congresos, foros y ferias de 2027 sobre servicio en órbita, encuentro y
proximidad (RPO), GNC y robótica espacial, con sus plazos de envío.

Suscripción (se actualiza sola):

```
https://raw.githubusercontent.com/MikeSnow/eventos-espacio-cal/main/eventos-espacio.ics
```

- Google Calendar: *Otros calendarios → + → Desde URL*.
- Outlook: *Agregar calendario → Suscribirse desde la web*.

Cada entrada enlaza a la web oficial del evento; las fechas que no están
confirmadas por el organizador lo dicen en la descripción. Se revisa cada lunes.
